# TuneFlow 桌面播放栏验收

日期：2026-08-12

## 几何与交互

- 桌面常驻播放栏固定为 96dp；封面 52×52dp；播放／暂停 52×52dp。
- 上一首、下一首、音质、歌词、队列的命中区域均不小于 44×44dp。
- 进度条交互高度为 28dp，视觉轨道保持 3dp；点击与拖拽均会 seek。
- 歌曲信息区整块可点击并进入全屏播放器；歌词与队列按钮会先选择对应视图再进入播放器。
- 加载／缓冲显示固定尺寸转圈并禁止重复触发；错误显示在歌曲信息下方，主按钮切换为“重试播放”。

- `flutter analyze`：通过，零问题。

## macOS Release 实机结果

- 产物：`build/macos/Build/Products/Release/TuneFlow.app`。
- Release entitlement 已加入 `com.apple.security.network.server`，允许 `just_audio` 在沙箱内创建本地 loopback 代理。
- 点击首页“继续播放”后，真实状态从“正在加载”进入“暂停”，进度由 0:00 增长到 0:18／4:31。
- 拖拽进度条后，位置从约 0:19 跳转到 3:34／4:31，并继续增长。
- 点击左侧歌曲信息区进入全屏播放器；音质入口展示 128k、320k、无损选项。
- 歌词与队列按钮的定向视图由 widget 回归测试覆盖。

## 已知边界

- 当前真实歌词内容存在编码乱码，这是歌词数据／解码链路的既存问题，不属于本次桌面播放栏改造。
- 本次只在 macOS Release 上做了真实音频与拖拽验收；Windows、Linux 依赖各自 runner 的构建和运行验收。
