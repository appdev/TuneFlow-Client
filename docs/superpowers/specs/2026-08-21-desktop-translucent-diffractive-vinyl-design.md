# TuneFlow 桌面斑驳透明彩胶与 Ambilight 设计

## 背景

当前桌面播放器的 `DesktopOrbitVinyl` 已具备封面驱动的彩色基底、封面折射环、
规则同心沟槽和唱片外衍射。实际效果仍偏向“纯色圆盘加线条”：16 条等距圆线
过于清晰，彩胶内部缺少真实压片常见的颜料沉积、云雾和大理石状流动纹理，
唱片边缘的独立光学结构也容易被读成边框。

用户提供的参考图明确了新的材质方向：中心使用歌曲封面；封面以外是由取色算法
驱动的半透明彩胶，兼具径向沉积和云雾大理石斑驳；唱片本身不出现任何边框；
唱片后方使用类似屏幕同步背光的 Ambilight，将封面颜色柔和扩散到背景。

本次采用“程序化压片纹理”方案。参考图只用于确定透明度、斑驳尺度和压片流动感，
不复制图中的品牌、封面内容、具体纹理像素或固定颜色。

## 目标

- 让中心封面以外的桌面唱片呈现真实彩色透明胶，而不是纯色渐变或规则线稿。
- 中心封面始终保持完全不透明，不继承树脂透明度、光斑混合模式或降级策略。
- 使用现有封面取色结果生成每首歌稳定、不同的径向沉积与云雾大理石斑驳。
- 不绘制常规黑胶式同心沟槽；材质层次完全由压片流动、颜料沉积与透光形成。
- 移除唱片外缘、封面外圈及材质层中的所有可辨认边框。
- 在唱片后方生成由封面配色驱动、方向固定的 Ambilight 柔光。
- 保持播放状态、18 秒旋转周期、中心封面语义、歌词安全区和底部控制不变。

## 非目标

- 不修改移动端 `MobileVinylRecord`、共享 `VinylRecord` 或移动播放器布局。
- 不修改 `ArtworkPaletteExtractor`、播放领域状态、音频行为、歌词和控制栏。
- 不增加外部纹理图片、Fragment Shader、第三方依赖或图片生成资源。
- 不加入泼墨动画、随机闪烁、音频频谱响应或逐帧重新生成纹理。
- 不复制参考图的品牌标识、中心标签或具体压片图案。

## 方案选择

采用 Flutter Canvas 程序化绘制，而不是 Fragment Shader 或灰度纹理图片：

- Canvas 能复用现有 `CustomPainter`、取色结果、降级策略和栅格缓存边界。
- 纹理由歌曲 `source:id` 的稳定种子控制，同一歌曲保持一致，不同歌曲自然变化。
- 相比固定图片，不会让所有歌曲重复同一纹理；相比 Shader，平台兼容和测试成本
  更低，也无需引入新的资产管线。

## 视觉结构

桌面唱片拆为固定 Ambilight、旋转彩胶和固定环形光斑三个节点，三者共享几何
中心。Ambilight 位于唱片后方；环形光斑位于旋转节点上方，但严格排除中心封面。

### 固定 Ambilight 节点

Ambilight 位于唱片后方，不进入 `RotationTransition`：

1. **颜色来源**：复用 `ArtworkPalette` 中的 `vinylAccent`、
   `backgroundBase` 和 `backgroundCompanion`，并只做受限的饱和度、亮度调整。
   不在唱片组件内重新解码封面或执行第二套取色。
2. **空间分布**：使用三至四个方向不同、相互重叠的柔光区域。颜色位置固定，
   形状略不对称，避免形成完整圆环。整体范围约为唱片直径的 `1.20–1.35` 倍，
   从唱片后方连续向外衰减。
3. **视觉权重**：柔光亮度低于唱片本体和中心封面，不产生边缘描边、独立色块、
   清晰光环或投影月牙，也不得侵入歌词主要阅读区。
4. **状态变化**：Ambilight 方向固定；换歌时随现有 `ArtworkPalette.lerp`
   配色过渡更新，不响应唱片角度、音频频谱或播放进度。
5. **亮暗适配**：浅色模式使用更高饱和度、更低明度和更高峰值 alpha，避免
   色区被浅背景洗掉；暗色模式保持较低峰值，避免形成过亮霓虹光。两种模式
   共享相同几何和固定方向行为。

标准路径使用有限模糊形成扩散；`AppGlassPolicy.blurEnabled == false` 时改用
预混合、低透明度的多层径向渐变，保持相同几何范围和色区方向。

### 旋转彩胶节点

旋转节点继续位于独立 `RepaintBoundary` 内，并按以下顺序合成：

1. **透明 PVC 基底**：使用 `vinylAccent` 派生深、中、浅色，提供整体色彩身份
   和有限透光。基底不能单独承担最终视觉，避免退化为纯色圆盘叠透明度。
2. **云雾大理石层**：绘制少量宽尺度、不规则、相互覆盖的弯曲色块和半透明
   流动带，形成参考图中的云雾、烟状和大理石斑驳。色块以主色的深浅变体及
   `backgroundCompanion` 为辅，禁止均匀分区和重复扇形。
3. **受控颜料流动层**：从中心封面外侧绘制数量受控、长短和宽度不一的柔化
   流动带。取消孤立随机颗粒、末端圆点和泼溅斑点；所有颜料纹理在靠近外缘前
   连续衰减，不能被圆形裁切截断后留下脏点或断头。
4. **统一半透明合成**：基底、云雾和颜料沉积先在离屏层中完成，再以约
   `.76–.80` 的统一透明度合成到播放器。单个内部图层不单独决定最终透明度，
   从而保证即使多层重叠也不会变成完全不透明，同时仍保留明确色彩和材质厚度。
5. **透明 PVC 内部明暗**：使用少量宽幅、非同心的低频明暗变化表达树脂厚度。
   该层随唱片旋转，但不承担主要镜面高光，不能形成圆弧轨道、外缘描边或散落
   光点。
6. **中心封面与轴孔**：歌曲封面继续保持清晰圆形裁切，直径约为唱片直径的
   `60%`，以独立节点在树脂合成完成后绘制，保持 `alpha = 1`，外侧不增加描边、
   色带或实体边框；轴孔保持现有尺寸和装饰语义。

### 固定环形光斑节点

光斑节点位于 `RotationTransition` 外、旋转唱片之上，只模拟固定环境光照在透明
树脂上的折射，不改变封面像素：

1. 使用外圆减去中心封面圆的偶奇环形路径裁切，内径与约 `60%` 的封面直径一致，
   因此任何高光、混合模式和透明度都不会覆盖中心封面。
2. 绘制两至三块方向固定、边缘柔和且宽度不同的椭圆／斜向渐变光斑，并保留少量
   低对比亮点。光斑使用低透明度提亮效果，不形成完整光环或均匀蒙版。
3. 树脂纹理随唱片旋转，而光斑方向保持固定，两者的相对运动形成缓慢流动与折射
   错觉；不增加第二个动画控制器，也不逐帧变形纹理。
4. 减少动态效果停止唱片旋转后，光斑仍作为静态材质信息保留；关闭模糊时使用
   无实时模糊的柔边渐变降级，几何和裁切范围不变。

### 无边框约束

- 不绘制唱片外缘 `stroke`、完整圆周高光、实体阴影轮廓或独立发光环。
- 不在中心封面外增加固定宽度的色带、描边或边框容器。
- 唱片轮廓仅由圆形材质裁切、透明 PVC 与背景的折射／明度差异自然形成。
- 为避免抗锯齿造成视觉描边，最外侧材质保持连续，边缘只做很窄的自然透明衰减；
  衰减不能形成可辨认的第二层圆盘。
- 颜料纹理使用独立径向遮罩，在半径约 `.90–.97` 的区域连续减弱；圆盘最外缘
  只保留干净的透明 PVC 基底和抗锯齿裁切，不出现随机黑点、亮点或截断纹理。

## 确定性与数据流

`DesktopPlayerStage` 继续把 `ArtworkPalette`、封面来源和歌曲
`source:id` 传给 `DesktopOrbitVinyl`。唱片组件以该字符串生成稳定的伪随机序列，
只用于确定云雾控制点、径向沉积位置、长度、宽度和透明度：

- 同一歌曲在重建、暂停和恢复后保持相同纹理。
- 不同歌曲即使取色相近，也具有不同斑驳布局。
- 随机序列只在歌曲或配色变化时重新计算，不读取时间、动画角度或每帧随机数。
- 缺失封面继续使用现有 fallback palette 和稳定歌曲种子，不能出现空白唱片。

## 动画、降级与性能

- 彩胶基底、斑驳、中心封面和轴孔继续以 18 秒匀速旋转；环形光斑与 Ambilight
  保持固定。
- 暂停、缓冲、完成和错误时停在当前角度；恢复后从当前角度续转。
- Ambilight 和环形光斑不闪烁、不随播放进度变化。
- 旋转彩胶、固定 Ambilight 和固定环形光斑分别栅格化。持续播放只更新唱片旋转
  变换矩阵，不重绘程序化纹理、Ambilight 或光斑。
- 减少动态效果继续禁止持续旋转；减少透明效果只切换 Ambilight 的模糊降级，
  不改变唱片尺寸、纹理种子或布局。
- 程序化路径和色块数量设定固定上限，避免唱片直径增大时绘制复杂度线性失控。

## 可访问性

- 中心封面继续提供唯一的歌曲封面语义。
- 彩胶、斑驳、反光、轴孔和 Ambilight 均排除语义且不接收指针事件。
- Ambilight 不是播放状态提示，且不得降低歌词、标题或控制的既有对比度。
- 减少动态效果仅停止唱片旋转，不移除静态材质信息。

## 实现边界

主要改动限定在：

- `lib/features/player/desktop_orbit_vinyl.dart`
- `test/features/player/desktop_orbit_vinyl_test.dart`
- 必要的 `test/features/player/player_screen_test.dart` 与桌面视觉基线
- `design.md` 中桌面沉浸式播放器的彩胶材质说明

不删除生产文件，不修改移动唱片组件。当前未提交的桌面彩胶实现应在原有结构上
收敛：用固定 Ambilight 取代可读作光环的衍射节点，用新的程序化材质 painter
取代规则 `TexturedVinylPainter`，并移除中心封面外的色带和边框容器。

## 验证

Widget 测试覆盖：

- Ambilight 存在且不位于 `player-desktop-orbit-turn` 下。
- 固定环形光斑存在且不位于旋转节点下，其环形裁切内径与中心封面直径一致。
- 彩胶基底、程序化斑驳、中心封面和轴孔仍位于同一旋转节点。
- 中心封面直径保持约 `60%`，外侧不存在边框绘制节点。
- 树脂最终透明度严格位于 0 与 1 之间，中心封面节点不使用 `Opacity`、透明
  `ColorFilter` 或树脂离屏合成层。
- 相同种子生成相同程序化参数，不同种子生成不同参数。
- 播放、暂停、恢复和减少动态效果行为不变。
- `blurEnabled` 开启时使用柔化 Ambilight，关闭时使用无模糊降级且几何不变。
- 旋转期间 Ambilight、环形光斑和程序化材质不被逐帧重绘。
- 移动唱片现有测试继续通过。

视觉验证覆盖 1024×768 和 1440×960 的亮色、暗色播放器，并至少使用冷色、
暖色、黑白和高对比封面确认：

- 中心封面清晰且没有外框；
- 外圈同时可见半透明 PVC、云雾大理石斑驳和受控流动色带；
- 背景能透过材质但不会使唱片接近无色透明，任何区域都不完全不透明；
- 唱片材质中不存在常规黑胶式同心沟槽或线圈感；
- 宽幅斜向高光能表达透明塑料质感，外缘保持干净且没有孤立污点；
- 唱片旋转时固定光斑方向不变，且中心封面的亮度和色彩不受光斑影响；
- 唱片外缘没有边框、完整光环或第二层圆盘；
- Ambilight 颜色来自封面配色，柔和扩散且不污染歌词和底部控制；
- 暂停和恢复前后 Ambilight 与环形光斑方向不变。

## 验收标准

桌面播放器显示任意歌曲时，中心封面清晰且约占唱片直径的 60%，封面外不出现
描边或色带。外圈呈现由封面取色驱动的半透明彩胶，具有稳定但不重复的云雾、
大理石和受控流动色带，不出现常规黑胶式同心沟槽或孤立颗粒污点。整张唱片以受控的统一
透明度合成，背景可感知但唱片仍保持饱满色彩。中心封面保持完全不透明。唱片
后方出现不对称、无环形边界的 Ambilight 柔光，并随歌曲配色变化；唱片上方存在
只覆盖外圈树脂的固定柔和光斑。唱片旋转时树脂纹理从固定光斑下经过，形成折射
与流动错觉，Ambilight 和光斑方向均保持固定。移动端、歌词、播放控制、响应式
安全区和播放状态行为均不发生变化。
