# 移动端二级页面导航层级设计

## 背景

应用通过 `StatefulShellRoute.indexedStack` 承载一级页面和它们的嵌套路由。移动布局的 `AppShell` 当前只在全屏播放器中移除 `AppMobileDock`，因此歌单、专辑、设置等二级页面仍显示五栏底部导航。用户既可以继续切换一级栏目，也缺少统一、明确的层级返回入口，这不符合常见移动应用的主导航与详情导航分工。

`AppMobileDock` 目前同时负责迷你播放器和五栏导航。本次设计将两者的可见性语义分开：二级页面不显示主导航，但继续保持正在播放内容可达。

## 目标

- 五栏底部导航只出现在移动端一级页面。
- 移动端二级页面隐藏五栏导航，并提供明确的顶部返回操作。
- 有当前歌曲时，二级页面继续显示迷你播放器；没有歌曲时底部不保留空白。
- Android 系统返回和 iOS 返回手势继续遵循现有路由栈。
- 桌面端侧栏、桌面迷你播放器和全屏播放器行为不变。
- 新增路由默认按二级页面处理，避免未来因遗漏配置而泄漏主导航。

## 页面层级规则

移动端一级页面采用精确路径白名单：

- `/`
- `/search`
- `/discover`
- `/playlists`
- `/more`

只有这些路径显示五栏导航。查询参数不影响页面层级。

所有其他 Shell 内路径在移动端均按二级页面处理，包括：

- 搜索结果进入的在线歌单和专辑详情；
- 发现页进入的在线歌单详情；
- 我的歌单详情和本地音乐；
- “更多”下的下载、音源、设置和关于；
- 移动端访问 `/square`、`/charts`、`/downloads`、`/settings`、`/sources` 及其深层路径；
- 未来新增但尚未加入一级白名单的路径。

连接页位于 Shell 外，不受此规则影响。全屏播放器继续使用根 Navigator，并同时隐藏主导航和迷你播放器。

## 组件与职责

### 路由层级判定

在应用 Shell 层提供一个可独立测试的纯函数，根据当前 location 判断移动端是否显示主导航。判定采用一级路径白名单，而不是维护不断增长的二级路径黑名单。

该判定只控制移动布局。桌面布局继续按照现有 location 选择侧栏栏目。

### 移动 Dock

`AppMobileDock` 增加是否显示五栏导航的显式输入，并支持两种组合：

1. 一级页面：有歌曲时显示迷你播放器，其下显示五栏导航；无歌曲时只显示五栏导航。
2. 二级页面：有歌曲时只显示迷你播放器；无歌曲时返回零尺寸内容，不占据安全区或底部高度。

迷你播放器与五栏导航保持各自现有视觉样式。二级页面中移除两者之间只用于组合布局的间距。

### 返回操作

提供共享的移动端返回按钮样式，并将其接入二级页面的顶部标题区域。按钮满足现有图标规范：使用 Lucide 普通界面图标、至少 44 px 触控目标、中文语义标签和 Tooltip。

返回行为遵循以下顺序：

1. 当前 Navigator 可以弹出时，弹回实际来源页面。
2. 深链直接进入且没有可弹出的页面时，回到所属一级页面：搜索详情回 `/search`，发现及广场/排行榜详情回 `/discover`，歌单和本地音乐回 `/playlists`，“更多”功能页回 `/more`。
3. 未识别的二级路径兜底回首页 `/`。

系统返回和手势返回继续由同一路由栈处理，不建立第二套页面历史。

## 状态与布局

- 隐藏五栏导航不重建 `StatefulNavigationShell`，一级分支的滚动位置、搜索状态和已加载数据继续保留。
- 在一级页与二级页之间切换时，当前播放状态和迷你播放器实例的数据来源不变。
- 二级页面的内容底部只为实际存在的迷你播放器让位；无歌曲时内容可以延伸至系统安全区。
- 从二级页打开全屏播放器，返回后恢复此前的二级页与“仅迷你播放器”形态。

## 异常与边界

- location 带查询参数时仍按 path 判定，不会误隐藏一级导航。
- 未登记的新路径默认隐藏五栏导航，以安全的二级语义呈现。
- 深链无返回栈时使用明确的栏目根路由，避免返回按钮无响应。
- 播放队列变为空后，二级页底部 Dock 立即收起且不留下间距。

## 验证

新增或调整测试覆盖：

- 一级路径显示五栏导航，典型二级路径和未知路径不显示；
- `/search` 与 `/search/...`、`/more` 与 `/more/...` 的边界判定；
- `AppMobileDock` 在一级/二级、有歌曲/无歌曲四种组合下的渲染与占位；
- 从歌单、专辑和“更多”进入典型二级页后，五栏导航消失且顶部返回按钮存在；
- 返回按钮弹回来源页，深链无历史时回到正确一级页；
- 二级页迷你播放器仍能打开全屏播放器，返回后导航可见性正确；
- 桌面侧栏、桌面迷你播放器和全屏播放器现有测试继续通过。

实现阶段使用聚焦的路由、Shell、Dock 和典型页面 Widget 测试验证，不扩大到无关页面重构。
