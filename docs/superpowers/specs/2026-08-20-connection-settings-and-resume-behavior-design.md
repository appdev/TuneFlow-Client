# 连接设置精简与网络切换行为设计

## 目标

精简客户端设置首页的 Service 连接信息，把地址配置移入二级页面；修正内网连接被显示为外网的问题；确保 App 前后台切换不会触发连接探测或音乐数据刷新，仅在网络连接类型实际变化时重新选择 Service 地址。

## 配置归属

- 首次连接/备用地址属于当前客户端，保存在客户端本地，作为候选地址的最终兜底。
- 内网访问地址和外网访问地址属于 Service，通过 Service 设置接口保存，供所有客户端共享。
- Service Web 的网络设置页也可编辑内网访问地址和外网访问地址，与客户端二级页使用同一份 Service 配置。
- 客户端冷启动继续优先使用上次成功连接地址，以缩短恢复连接时间。

## 客户端交互

### 设置首页

设置首页仅显示一条可点击的“Service 连接”摘要。右侧根据当前状态显示以下一种文案，并附带进入二级页面的箭头：

- 内网连接
- 外网连接
- 备用地址连接
- 暂不可达

首页不再显示当前 URL、延迟、API 版本、最近检查时间、地址输入框或“重新连接”按钮。

### 侧栏入口

桌面侧栏底部的“Service 已连接”改为连接设置入口。点击后进入二级连接设置，不调用断开连接，不清除任何已保存地址，也不影响正在播放的音乐。

### 二级连接设置

二级页面包含三个带固定标签和说明的地址字段：

1. 首次连接/备用地址：写入当前客户端本地设置。
2. 内网访问地址：通过 Service 设置接口写入 `service.lanOrigin`。
3. 外网访问地址：通过 Service 设置接口写入 `service.externalOrigin`。

用户通过“保存并检测”提交修改。提交前校验地址格式；保存和探测全部成功后才切换活动地址。若保存或探测失败，显示明确错误，保留当前已连接会话和原有效配置，不跳转到首次连接页。

## 连接方式判定

连接方式由端点选择器返回的候选角色与实际成功地址共同确定：

- 成功地址对应内网候选时显示“内网连接”。
- 成功地址对应外网候选时显示“外网连接”。
- 成功地址仅对应首次手动地址时显示“备用地址连接”。
- 所有候选不可达时显示“暂不可达”。

设置页面不再发起一套独立诊断，也不根据 IP 字符串猜测网络类型。连接协调器持有的实时结果是客户端连接状态的唯一来源。

## 探测触发规则

- 冷启动：使用上次成功地址恢复，并按既定候选策略完成必要连接。
- 网络类型实际变化：重新探测。Wi-Fi、有线、蜂窝或离线集合与上次观测结果一致时不触发。
- App 从后台回到前台：不探测。
- 用户点击“保存并检测”：针对新配置执行显式探测。
- 单纯打开设置首页或二级连接设置：不探测。

候选顺序保持既定规则：Wi-Fi/有线下为内网地址、外网地址、首次手动地址；非 Wi-Fi 下为外网地址、首次手动地址。每个候选最多重试三次，每次失败后间隔两秒。

## 状态与页面生命周期隔离

连接状态更新分为“可用性变化”和“诊断展示变化”。路由只订阅是否已连接这一导航条件，不因延迟、网络类型、检查时间或活动地址更新而重建。连接方式文案由局部状态组件订阅。

Service API 对象在自动地址切换时保持稳定，仅更新其 base URL。首页、音乐管理、播放控制器及其数据仓库不得因连接诊断更新而重建。只有领域事件、用户主动刷新或真实数据失效事件才能触发对应音乐数据刷新。

## Service Web

Web 的“网络设置”页保留内网和外网两个字段，并为每个输入框增加始终可见的标签与用途说明。空值代表不启用该候选地址。运行中的旧 Web 构建需要重新构建或部署后才能显示这部分界面。

## 错误处理

- 地址格式错误：在对应字段附近提示，不发送保存请求。
- Service 设置保存失败：保留原配置和当前连接，提示保存失败。
- 新候选探测失败：保留当前连接，提示新地址暂不可达。
- 网络变化后全部候选不可达：状态改为“暂不可达”，但不销毁稳定 API 对象或刷新音乐页面；后续网络再次变化或用户显式检测时重试。

## 验证范围

- 设置首页只呈现精简摘要，点击可进入二级连接设置。
- 侧栏“Service 已连接”点击进入连接设置且不会调用断开逻辑。
- 内网、外网和备用地址分别写入正确的持久化位置。
- 活动候选角色正确映射为内网、外网或备用地址连接。
- 设置页面打开和 App 前后台切换均不会发起探测。
- 网络类型未变化时不探测，实际变化时按候选顺序和重试策略探测。
- 连接诊断更新和自动 base URL 切换不会重建路由、首页控制器或音乐数据仓库。
- Service Web 中两个地址字段具有可见标签、说明并可持久化。

## 非目标

- 不改变既定候选优先级、重试次数或重试间隔。
- 不增加后台定时探测。
- 不自动断开当前 Service。
- 本次不执行发布或部署；是否部署由用户另行授权。
