# 连接页品牌与输入体验调整

## 目标

让连接页使用 TuneFlow 自有品牌图标，移除标题下方的说明文案，并让 Service 地址示例以占位符呈现，而不是作为可提交的实际输入值。

## 界面设计

- 将当前音乐符号图标替换为项目现有资源 `assets/branding/TuneFlow.png`。
- 保留“连接音流服务”标题。
- 完整移除标题下方的连接说明文案及其专属间距。
- Service 地址输入框初始值为空。
- 输入框根据运行平台显示占位符：
  - Android：`http://10.0.2.2:3124`
  - 其他平台：`http://127.0.0.1:3124`
- 用户输入、表单校验、连接按钮和错误提示的现有行为保持不变。

## 实现边界

改动仅限连接页及其组件测试。继续复用现有品牌图片和 `defaultServiceOrigin` 的平台地址选择逻辑，不新增资源、依赖或连接配置。

## 验证

组件测试应确认：

- 页面使用 TuneFlow 品牌图片，不再显示原音乐符号图标。
- 说明文案不再渲染。
- 输入框 controller 的初始文本为空。
- Android 与非 Android 平台显示各自对应的占位符。
- 用户手动输入地址后，原有连接流程仍读取并保留该输入值。
