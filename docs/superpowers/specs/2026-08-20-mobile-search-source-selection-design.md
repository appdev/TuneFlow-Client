# 移动端搜索来源选择设计

## 目标

修复移动端搜索中分类与音源切换的误导和迟滞，让歌曲、专辑、歌单只展示当前分类真实支持的来源，并统一使用项目级选择弹窗。

## 已确认事实

- 指定 Service `http://192.168.0.172:3124/` 的能力接口显示：五个来源都支持歌曲与歌单搜索，只有网易音乐支持专辑搜索。
- 对五个来源直接调用专辑搜索接口时，酷我、酷狗、QQ、咪咕返回 `SOURCE_CAPABILITY_UNAVAILABLE`，网易音乐正常返回结果。
- 当前搜索来源弹窗只复用了 `AppBottomSheet.showContent` 外壳，选项列表仍由搜索页手写。
- 从“全部来源/歌曲”进入集合分类时，当前实现会先等待一次无关的单曲搜索，然后才切换分类；选择集合分类不支持的来源还会静默退回歌曲页。

## 行为设计

### 来源范围

- 歌曲：展示所有支持歌曲搜索的来源，并追加“全部来源”。
- 歌单：只展示支持歌单搜索的来源，不展示“全部来源”。
- 专辑：只展示支持专辑搜索的来源。当前 Service 下仅显示网易音乐，并说明“当前仅网易音乐支持专辑搜索”。

### 选择弹窗

在 `AppBottomSheet` 增加通用 typed selection 入口。它接收标题、可选说明、选项列表和当前值，返回所选 typed value。移动端复用项目现有操作弹窗视觉：选项内容卡片与底部“取消”卡片分离；桌面端沿用自适应居中对话框。选项支持滚动、当前项选择语义、禁用态、稳定 key 和至少 44 px 触控目标。

搜索页不再构造自己的来源按钮列表，只负责根据当前分类生成有效选项及说明。

### 状态转换

来源与目标分类必须在控制器中一次性确定。进入专辑或歌单时，如果当前来源不支持目标分类，直接选择第一个支持来源并请求目标分类；不得先请求无关的歌曲结果。切换来源后保持当前分类，不允许静默跳回歌曲。

## 边界

- 不新增 Service 音源能力，也不把不支持专辑搜索的来源伪装成可用。
- 不改变桌面搜索结果结构、播放、收藏、下载、搜索历史或分页行为。
- 不修改现有未提交的设置、关于、更新检查和字体工作。

## 验证

- 通用组件测试验证 typed 返回值、选中语义、长列表滚动和自适应呈现。
- 搜索控制器测试验证来源与分类原子切换，不产生无关歌曲请求。
- 搜索页面测试验证歌曲、歌单、专辑各自的来源集合和专辑限制说明。
- Android 35 Pixel 8 模拟器连接指定 Service，验证歌曲聚合、五来源歌单切换、网易专辑限制及弹窗视觉。
